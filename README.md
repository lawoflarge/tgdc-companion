# TGDC Capture — downloads

This repository exists for one reason: to host the signed installers for
**TGDC Capture** so that anyone can download them without a GitHub account.

There is no source code here. The application is built from a private
repository; a release workflow there signs, notarises and uploads the artifacts
to the Releases page of this repository.

**Get the app at [thegeneraldata.com/app](https://thegeneraldata.com/app).**
That page publishes the version, the size and the SHA-256 of each build and
links to the files below. Checking the hash you downloaded against the hash on
that page is the point of publishing it.

## What the builds are signed with

|---|---|

| Windows | not code-signed yet — the download page explains what SmartScreen shows and why |
